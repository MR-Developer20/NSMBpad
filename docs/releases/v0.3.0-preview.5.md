# KartPad v0.3.0-preview.5

Preview 5 removes two dead ends reported against the preceding previews.

## What changed

- On iPhone and iPad, **Import from This Installation's Folder…** still uses a
  supported WBFS, ISO, or extracted DATA folder already stored in the current
  signed app's Files container. If that container is empty, KartPad now opens
  the normal Files picker immediately instead of stopping at a "not found"
  alert. This also covers sideloading tools that assign a new bundle identifier
  or protection suffix and therefore create a different app container.
- The normal Files picker still requests a private copy from the selected Files
  provider and keeps KartPad's extension, disc-header, exact `RMCP01` revision,
  and extracted-tree validation.
- The native macOS runtime no longer intentionally hides the pointer after five
  idle seconds. Opening the F10/controller settings bar explicitly requests a
  visible cursor in windowed, borderless, and fullscreen use.

Preview 5 retains Preview 4's experimental standard `.mii` import/management
and experimental macOS-only direct Wii Remote/Nunchuk path. Those features
still require results from real exported Miis and physical Wii hardware.

## Installation

The release asset is an unsigned ARM64 iPhone/iPad IPA. Verify `SHA256SUMS`,
re-sign the IPA with your own Apple identity, and update in place with the same
bundle identifier and signing identity when possible. Supply your own legally
obtained PAL `RMCP01` revision 0 WBFS/ISO; no game image, extracted game data,
save, signing identity, provisioning profile, or Retro Rewind pack is included.

The macOS pointer repair is included in the tagged source and the documented
self-build workflow. No macOS binary is attached to this release.

## Remaining boundaries

- Import success on the Issue #1 reporter's exact Feather-signed iPad remains a
  hands-on acceptance gate.
- Pointer/menu behavior and Wii Remote/Nunchuk input on the Issue #5 reporter's
  MacBook Air remain hands-on acceptance gates.
- RetroAchievements remains a separate researched feature and is not included.
- Retro WFC remains subject to the external service's current availability;
  Original Mario Kart Wii and Retro Rewind offline play are separate.
