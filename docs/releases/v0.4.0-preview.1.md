# KartPad v0.4.0-preview.1

This preview introduces KartPad's first independently implemented native Apple
TV build and keeps the existing iPhone/iPad build available in the same
release.

## Apple TV hardware bring-up

- Native arm64 tvOS 17 application using the existing ahead-of-time translated
  Original Mario Kart Wii and Retro Rewind profiles.
- Focus-driven setup screens and explicit Extended Gamepad requirement; the
  Siri Remote does not become a racing controller.
- Private RMCP01 data staging from a paired Mac, with disc ID, revision, Wii
  header, required-file, and exact `main.dol` validation.
- On-device download, size/hash verification, and safe installation of the
  pinned official Retro Rewind 6.12.4 pack.
- Rebuildable game/mod content in Caches, while configuration, NAND, saves, and
  runtime logs remain in Application Support.
- Original three-layer KartPad Apple TV icon and Top Shelf artwork. No Wii
  banner or user-supplied game artwork is included.
- Backup and path-redacted diagnostic collection scripts for paired devices.

The tvOS IPA is physically unaccepted. It builds and audits cleanly, but the
maintainer does not own Apple TV hardware. Testers should follow the included
`TVOS_TESTING.md`, stop at the first failure, and report the exact app hash,
Apple TV/tvOS version, controller, signing method, mode, and last completed
step. Do not report Apple TV support as complete yet.

## iPhone and iPad

The iPhone/iPad IPA is app version 0.4.0 build 13 and carries forward Preview
5's accepted dual Original/Retro Rewind experience, Files-provider import
repair, touch/controller support, and experimental Mii management. Direct Wii
Remote/Nunchuk pairing remains experimental and macOS-only.

## Installation and boundaries

Both IPAs are unsigned and must be re-signed locally. Supply your own legally
obtained PAL `RMCP01`, revision-0 game data. Neither artifact includes a game
image, extracted game assets, Retro Rewind pack, saves, signing material, or
provisioning profile. The executables contain ahead-of-time translated retail
logic under the same unresolved-rights community-preview boundary documented
in `RIGHTS_AND_LICENSES.md`.

Retro Rewind offline play is separate from Retro WFC. Public online-service
compatibility remains unaccepted while the external service is unavailable.
