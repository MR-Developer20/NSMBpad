# KartPad v0.4.0-preview.2

This preview updates KartPad for Retro Rewind 6.12.5 and repairs the universal
iPhone/iPad settings menu introduced in Preview 1.

## Retro Rewind 6.12.5

- Pins and verifies the official 6.12.5 full archive, `Code.pul`, and
  Riivolution XML.
- Regenerates the ahead-of-time translated Retro Rewind graph from the updated
  code instead of accepting unknown executable content at runtime.
- Advances the pinned Retro Rewind and WFC patcher source references.
- Adds a read-only daily version check and a deterministic profile-update
  helper so future upstream releases are detected and prepared quickly.

Because Retro Rewind includes executable PowerPC code, a `Code.pul` change
still requires a new KartPad build. Apple platforms do not permit KartPad to
turn newly downloaded PowerPC code into executable ARM64 code at runtime. The
version gate therefore remains fail-closed rather than launching a mismatched
online build.

## iPhone and iPad

- App version 0.4.0 build 14.
- Keeps the consolidated KartPad three-dot menu after inherited settings
  refreshes. The menu title remains KartPad and does not expose the obsolete
  SunPad performance or 60 FPS experiments.
- Includes the existing touch, motion, controller, import, save, and dual-mode
  behavior.

The iPhone/iPad app builds and audits cleanly. Retro Rewind 6.12.5 translation
and packaging are validated, but physical 6.12.5 gameplay acceptance is still
requested from testers. The preceding 6.12.4 iPad flow remains the most recent
accepted Retro Rewind install-and-race result.

## Apple TV

- App version 0.4.0 build 2.
- Carries the same Retro Rewind 6.12.5 translated graph into the native arm64
  tvOS 17 hardware-bring-up build.

The tvOS IPA remains physically unaccepted because the maintainer does not own
Apple TV hardware. Testers should follow `TVOS_TESTING.md`, stop at the first
failure, and report the exact app hash, Apple TV/tvOS version, controller,
signing method, mode, and last completed step.

## Installation and boundaries

Both IPAs are unsigned and must be re-signed locally. Supply your own legally
obtained PAL `RMCP01`, revision-0 game data. Neither artifact includes a game
image, extracted game assets, the Retro Rewind pack, saves, signing material,
or a provisioning profile. Live public Retro WFC compatibility remains a
separate external acceptance gate.
