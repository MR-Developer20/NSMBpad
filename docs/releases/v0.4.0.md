# KartPad v0.4.0

KartPad 0.4.0 is the second stable community release. It brings the complete
dual-mode Mario Kart Wii and Retro Rewind experience to iPhone and iPad, and
includes a separate experimental Apple TV tester build.

## iPhone and iPad

- App version 0.4.0 build 15.
- Supports Original Mario Kart Wii and the current Retro Rewind 6.12.5 pack.
- Keeps the consolidated KartPad three-dot menu on both iPhone and iPad.
- Uses the maintainer-tested compact touch layout for untouched iPhone
  installs while preserving existing custom layouts and all iPad layouts.
- Lets users move, resize, hide, and restore individual touch controls. The
  grouped D-pad performs tricks and wheelies and can also be hidden.
- Returns from the layout editor directly to Touch Control Settings with an
  explicit **Back** action.
- Includes the existing acceleration lock, motion steering, controller
  handoff, private game-data import, save handling, and experimental Mii import.

The exact candidate was installed in place and physically exercised on the
maintainer's iPhone. Retro Rewind launched, the updated settings hierarchy
worked, controls could be hidden, and the editor returned correctly without
removing the existing app container, preferences, game data, or saves.

## Retro Rewind updates

KartPad pins and verifies the official Retro Rewind 6.12.5 archive, `Code.pul`,
and Riivolution XML and includes the corresponding ahead-of-time ARM64
translation. A read-only daily watcher detects future Retro Rewind releases,
and a deterministic updater prepares the next reviewed KartPad profile.

Retro Rewind executable updates still require a KartPad release. Apple
platforms do not permit KartPad to turn newly downloaded PowerPC code into
executable ARM64 code at runtime, so the compatibility check fails closed
instead of launching mismatched code.

## Experimental Apple TV build

- App version 0.4.0 build 3.
- Native arm64 tvOS 17 build with the same Original/Retro Rewind 6.12.5 graph.
- Requires an Extended Gamepad and private game-data staging from a paired Mac.

The Apple TV artifact has passed source, compilation, bundle, dependency,
privacy, signing-residue, and private-data audits. It has not been run on
physical Apple TV hardware by the maintainer, so tvOS remains an experimental
tester path rather than an accepted supported platform. Follow
`TVOS_TESTING.md` and report the first failing step.

## Installation and boundaries

Both IPAs are unsigned and must be re-signed locally. Supply your own legally
obtained PAL `RMCP01`, revision-0 game data. Neither artifact includes a disc
image, extracted game assets, Retro Rewind content, saves, signing material, or
a provisioning profile. Public Retro WFC availability and production online
acceptance remain separate from offline Original and Retro Rewind support.
