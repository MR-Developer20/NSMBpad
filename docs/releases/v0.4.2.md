# KartPad v0.4.2

KartPad 0.4.2 is a maintenance release with refreshed unsigned IPAs for the
accepted iPhone/iPad path and the experimental Apple TV path.

## iPhone and iPad

- App version 0.4.2 build 16.
- Keeps the stable dual-mode Original Mario Kart Wii and Retro Rewind 6.12.5
  experience from 0.4.0.
- Makes the guest `SCGetAspectRatio` result follow KartPad's existing mobile
  aspect selection, removing a mismatch between host presentation state and
  the game-visible system setting.
- Preserves the accepted touch, motion, controller, game-data, and save paths.

The iPhone/iPad package is the stable community release path. This maintenance
build passed the complete dual-mode iOS Simulator build and package audits; its
shared behavior remains based on the previously accepted physical iPhone/iPad
release.

## Experimental Apple TV build

- App version 0.4.2 build 5.
- Carries forward the 0.4.1 cache-root storage correction.
- Uses a generic AArch64 compiler baseline and explicitly disables RCpc
  instruction selection for WiiCompiled tvOS targets.
- Fails the build if Xcode drops the required compiler forwarding sequence and
  fails the app audit if the final executable contains an RCpc load instruction.
- Keeps fixed 16:9 presentation, the controller-required screen, and the
  Original/Retro Rewind launch chooser.

The exact executable passed the complete unsigned tvOS build, bundle audit, and
RCpc instruction scan. This is defensive compiler hardening, not confirmation
that the app works on every Apple TV or specifically on A12 hardware. tvOS
remains an experimental tester path.

Controller rumble, a tvOS Settings bundle, and multichannel audio are not part
of this release.

## Installation and boundaries

Both IPAs are unsigned and must be re-signed locally. Supply your own legally
obtained PAL `RMCP01`, revision-0 game data. Neither artifact includes a disc
image, extracted game assets, Retro Rewind content, saves, signing material, or
a provisioning profile. Public Retro WFC availability and production online
acceptance remain separate from offline Original and Retro Rewind support.
