# KartPad v0.4.3

KartPad 0.4.3 is a community-maintenance release focused on correctness,
startup stability, and optional iPhone controls. It contains no Android
changes.

## iPhone and iPad

- App version 0.4.3 build 17.
- Fixes Retro Rewind cup and course names by preserving dynamic dispatch for
  functions overridden by the selected profile.
- Prevents an installed-version startup crash by deferring viewport reapply
  until SDL has created the app window.
- Reduces iOS audio buffering with 512-frame SDL chunks and a 60 ms producer
  queue limit.
- Adds an opt-in **Shake Tricks / Wheelies** setting. It is off by default,
  removes gravity from the motion signal, emits one Classic D-pad Up press per
  deliberate shake, and yields to a connected physical controller.
- Preserves existing game-data, settings, and save locations.

The contributor tested the four fixes together on an iPhone 17 Pro, including
Retro Rewind 6.12.5 races and AirPods Max audio. Maintainer validation covered
the merged translator, native tests, complete unsigned device build, and app
audit. Older-device audio behavior and broader physical-device acceptance
remain monitoring boundaries.

## Experimental Apple TV build

- App version 0.4.3 build 6.
- Includes the shared Retro Rewind dynamic-dispatch correction.
- Carries forward the 0.4.2 generic AArch64 compiler baseline, RCpc rejection,
  and the accepted 0.4.1 cache-root storage correction.
- Does not include the iOS-only shake, viewport, or audio changes.

Apple TV remains an experimental tester path. Physical acceptance of the exact
0.4.3 tvOS artifact, including A12 compatibility, is still required.

## Installation and boundaries

Both IPAs are unsigned and must be re-signed locally. Supply your own legally
obtained PAL `RMCP01`, revision-0 game data. Neither artifact includes a disc
image, extracted game assets, Retro Rewind content, saves, signing material, or
a provisioning profile. Public Retro WFC availability and production online
acceptance remain separate from offline Original and Retro Rewind support.
