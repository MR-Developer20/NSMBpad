# KartPad v0.4.4

KartPad 0.4.4 restores compatibility with the current Retro Rewind 6.12.7
release and makes the next upstream update visible and repeatable for the
maintainer.

## iPhone and iPad

- App version 0.4.4 build 18.
- Downloads, verifies, and installs the official Retro Rewind 6.12.7 full pack.
- Includes a freshly translated 6.12.7 native graph built from the changed
  executable `Code.pul`.
- Gives a clearer explanation when a future Retro Rewind executable update
  requires a matching KartPad build; Original Mario Kart Wii remains available.
- Keeps existing KartPad game-data, save, settings, controller, touch, motion,
  audio, and display paths unchanged.

## Apple TV

- Experimental app version 0.4.4 build 7.
- Uses the same Retro Rewind 6.12.7 graph and exact full-pack verification.
- Retains the cache-root storage correction, generic AArch64 compiler baseline,
  RCpc exclusion, and final-binary audit.
- Physical acceptance of the exact 0.4.4 tvOS artifact is still required;
  Apple TV remains experimental.

## Future Retro Rewind updates

KartPad now checks the official feed daily and automatically opens one
deduplicated compatibility issue when it advances. Maintainers can download or
resume the latest official full pack and refresh all archive, `Code.pul`, and
XML pins with:

```sh
python3 scripts/update-retro-rewind-profile.py --latest
```

An upstream `Code.pul` change still requires a KartPad release because KartPad
translates that PowerPC executable code to ARM64 ahead of time. Loading a newly
generated executable at runtime would violate the no-JIT/signed-code boundary
on iOS and tvOS. The automated watcher and updater remove discovery and repin
busywork without moving private user-owned game inputs into hosted CI.

## Online status

Retro WFC's public health and room endpoints were reachable and reported active
service on 6 September 2026. That confirms the external service is back; it is
not yet proof that the exact KartPad 0.4.4 artifact completes production login,
matchmaking, a race, results, and reconnect. Those are separate acceptance
gates.

## Distribution boundary

The release contains separate unsigned ARM64 IPAs for iPhone/iPad and
experimental Apple TV. Re-sign before installing and supply your own legally
obtained supported PAL `RMCP01` revision 0 game data. Neither IPA contains a
disc image, extracted game assets, the Retro Rewind pack, saves, credentials,
signing material, provisioning profiles, or device identifiers.
