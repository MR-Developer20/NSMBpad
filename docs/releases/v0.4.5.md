# KartPad v0.4.5

KartPad 0.4.5 makes the player identity used by Mario Kart Wii and Retro
Rewind editable on iPhone and iPad.

## Player identity

- App version 0.4.5 build 19.
- Replaces the import-only Mii menu with **Game Data & Saves → Player
  Identity…**.
- Adds a 1–10 character player-name editor for the built-in or an imported
  Mii.
- Updates every existing original-game and Retro Rewind license linked to that
  Mii, so the new name is used online without replacing the friend code,
  online account, or race progress.
- New licenses created with that Mii inherit the chosen name.
- Stages only the identity intent until the next launch, then updates the newest
  live save, validates both checksums, and backs up both files before applying
  them.
- Keeps standard 74-byte `.mii` import available for users who also want to
  change the Mii appearance.

## Compatibility

This is an iPhone/iPad hotfix on top of 0.4.4. It retains the current Retro
Rewind 6.12.7 translated graph, version checks, installer, controls, and
user-data paths. The experimental Apple TV artifact remains at 0.4.4.

## Distribution boundary

The release contains an unsigned ARM64 IPA for iPhone and iPad. Re-sign it and
supply your own legally obtained supported PAL `RMCP01` revision 0 game data.
The IPA contains no disc image, extracted game assets, Retro Rewind pack,
saves, Mii database, signing identity, provisioning profile, or device
identifier.
