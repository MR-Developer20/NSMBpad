# KartPad v0.4.6

KartPad 0.4.6 separates Mario Kart licenses from Mii appearances so existing
online accounts can be renamed or removed without guessing which record is
being changed.

## Existing licenses

- App version 0.4.6 build 20.
- Adds **Game Data & Saves → Player Identity… → Manage Existing Licenses…**.
- Lists the exact Original or Retro Rewind profile, one-based slot, and current
  name for every active license.
- Renames a selected license while retaining its friend code, online account,
  records, and progress. A matching Mii is renamed at the same time when one is
  present.
- Deletes only the selected license after a second destructive confirmation
  that names its profile and slot.
- Stages changes until the next launch, validates the live save again, creates
  backups, writes atomically, and repairs the RKSYS CRC-32.
- Prevents **Remove Mii Appearance…** from removing a Mii that is still linked
  to an existing license.

## Screenshot recovery

- Reasserts the persistent three-dot button immediately after iPadOS reports a
  screenshot and again on the next main-loop pass.
- Keeps the existing foreground and UIKit-surface recovery paths intact.

## Compatibility

This is an iPhone/iPad hotfix on top of 0.4.5. It retains the Retro Rewind
6.12.7 translated graph, installer, online compatibility, controls, and
user-data paths. The experimental Apple TV artifact remains at 0.4.4.

## Distribution boundary

The release contains an unsigned ARM64 IPA for iPhone and iPad. Re-sign it and
supply your own legally obtained supported PAL `RMCP01` revision 0 game data.
The IPA contains no disc image, extracted game assets, Retro Rewind pack,
saves, Mii database, signing identity, provisioning profile, or device
identifier.
