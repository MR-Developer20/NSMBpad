# KartPad v0.4.8

Version 0.4.8 build 22 improves player identity and touch controls on the
Apple builds. Original and Retro Rewind 6.12.7 remain in the same app.

## iPhone and iPad

- Fixes SDL intercepting changes in native text fields, which could dismiss
  the player-name keyboard after each character or backspace.
- Moves Player Identity to the first position in Game Data & Saves and adds
  the missing Game Data & Saves menu icon.
- Shows scheduled license names immediately in the manager, marked pending.
  Fully close and reopen KartPad to apply them to the game. Renaming preserves
  account, friend code and progress; deletion still requires confirmation.
- The movement stick is invisible when idle. Touch its expanded pickup area
  to place the stick under your thumb; release to return to neutral.
- New/reset iPad layouts put X/Y on the left, A/B/L/R/Z on the right, and Start
  near the right shoulder. The directional pad is hidden by default on both
  device sizes. The iPhone Start position remains at the top left.
- Existing custom positions, sizes and explicit visibility choices are kept.
  Layout editing still shows the movement stick for moving and resizing it.

## macOS

- Adds player-name and exact Original/Retro Rewind license management to
  **Data → Player Identity** with the same safe next-launch application.
- Prevents removing Mii appearances still linked to an existing license.

## Validation and limits

Synthetic save tests cover pending names, linked profiles, backups, exact-slot
deletion and preservation of unrelated account/progress bytes. The native
SDL/UIKit alert fixture retained keyboard focus through five characters and
two backspaces. All 68 Python checks and 16 native host tests passed. A UIKit
Simulator fixture exercises floating-stick pickup, touch ownership, axes,
cancellation, editing and resizing. Physical ergonomics and extended gameplay
remain separate acceptance checks; these tests are not a performance claim.
The local candidate installed and launched in place on the attached iPhone
and iPad; NAND and Retro Rewind saves matched the pre-update backups
byte-for-byte. The iPad chooser still recognized its installed 6.12.7 profile.
Live Mac review verified the identity menu, corrected popup spacing, and
typing/backspace without saving a test name.
Android work remains on its separate development branch and is not included.

## Distribution boundary

The unsigned IPA requires local re-signing. The Apple Silicon Mac app uses
ad-hoc signing. Both include ahead-of-time translated executable code, but no
disc image, extracted assets, Retro Rewind pack, saves, Mii database, account
data, signing identity, provisioning profile or device identifier. Supply your
own legally obtained supported PAL RMCP01 revision-0 data. This community
release does not resolve upstream or game-code rights.
